# 사이트가 바뀐 기록

[English](site-changes.md) | 한국어

needmoreeasy.com 자체가 어떻게 바뀌어 왔는지 적습니다. 브라우저에서 도는 컴파일러와
언어 자체가 바뀐 기록은 [변경 기록](changes)에 따로 있습니다 — 둘은 서로 다른 일이고,
읽는 사람이 어느 쪽이 바뀐 것인지 헤아리게 만들 이유가 없습니다.

## 2026-09-29

- **내 컴퓨터에 NME를 설치하는 일이 한 줄이 되었습니다.** 첫 화면 아래쪽에 macOS·Linux용
  명령 하나와 Windows PowerShell용 명령 하나가 있고, 각각 복사 단추가 따로 있습니다.
  내 컴퓨터에 맞게 미리 만든 `nme`를 받아, 릴리스에 함께 올라간 확인값과 맞지 않으면
  설치하지 않고, 새 터미널이 찾을 수 있는 곳에 넣습니다. 러스트와 Git을 설치하고 소스에서
  컴파일하는 일은 이제 필요 없습니다.
- **파이썬이 더 필요한지 설치 프로그램이 알려 줍니다.** 필요하면 어디서 받는지도 알려 줍니다.
- **좁은 휴대전화에서 글자를 크게 해도 화면이 옆으로 밀리지 않습니다.** 폭 320픽셀에
  글자 150%에서는 예제 선반과 그 아래 표시 글 때문에 쪽 전체가 화면보다 넓어졌습니다.
- **한국어 브라우저로 영어 가이드 링크를 열면 그 가이드의 한국어 쪽이 열립니다.** 전에는
  한국어 첫 화면으로 가 버려서, 링크가 가리키던 쪽을 잃었습니다.

## 2026-08-23

- **되돌리기와 다시 하기를 넣었습니다.** 자판은 Ctrl+Z와 Ctrl+Shift+Z(윈도우에서는
  Ctrl+Y도), 편집 칸 머리에 단추도 있습니다. 파일 셋과 예제 칸이 각각 자기 기록을
  가지므로, 파일을 옮겨 다녀도 그 파일에서 하던 것이 그대로 남습니다. 한글 한 글자는
  한 걸음이고, 이름 바꾸기처럼 여러 줄을 한꺼번에 고치는 일도 한 걸음입니다.
- **치는 동안 화면이 멈추지 않습니다.** 4,337줄짜리 예제에서 한 글자를 칠 때 화면이
  멈춘 가장 긴 순간이 3,966밀리초에서 0으로 줄었습니다. 컴파일을 다른 일꾼에게 넘기고,
  파이썬 칸을 통째로 다시 그리는 대신 바뀐 줄만 고쳐 그리며, 한글을 만드는 도중에는
  컴파일을 걸지 않습니다.
- **한 글자를 고쳤다고 화면이 위로 튀지 않습니다.** 프로그램이 잠깐 깨져도 파이썬 칸을
  비우지 않고 조금 전 결과를 흐리게 남깁니다. 무엇이 걸렸는지는 편집 칸 아래 띠가
  말합니다.
- **이름 바꾸기가 값 이름까지 찾습니다.** 전에는 「일」의 이름만 모아서 큰 프로그램에서도
  여섯 개뿐이었습니다. 지금은 가장 큰 예제에서 404개를 찾고, 고른 이름이 몇 곳에 있는지도
  보여 줍니다. 글 속에 같은 글자가 있어도 그것은 건드리지 않습니다.
- **찾기 칸이 한 글자마다 초점을 뺏지 않습니다.**
- **실행기의 두 파일이 서로 다른 판일 때 스스로 고칩니다.** 브라우저가 한쪽만 옛것으로
  들고 있으면 무엇을 눌러도 실행되지 않았는데, 이제 한 번은 조용히 다시 받아 고치고,
  그래도 안 되면 새로 고침을 권합니다.
- **예제 둘을 더했습니다** — 순수 문장문법으로 쓴 RSA 공개키 암호와, 2009년 1월의
  비트코인을 재현한 프로그램입니다. 뒤엣것은 진짜로 채굴하기 때문에 브라우저에서
  4분쯤 걸립니다.
- 디자인을 더 덜어 내고, 예제를 코드 칸 바로 위로 올리고, 찾기와 이름 바꾸기를
  넣었습니다. 화면의 모든 글자와 테두리 대비를 재어서 고쳤고, 건너뛰기 링크가 실제로
  쓰는 칸으로 가게 고쳤습니다.

- 긴 프로그램에서도 실행 단추가 손에 닿게 했습니다.

## 2026-08-19

- **코딩 화면**을 넣었습니다. 창 전체를 편집 칸에 줍니다.
- **편집 칸의 줄과 파이썬의 줄을 짝지어** 보여 줍니다. 한 문장이 한 줄이라는 사실이
  화면에서 보입니다.
- **정리하기**를 넣었습니다. 아무렇게나 쓴 프로그램을 고른 표기로 다시 씁니다.
- 프로그램이 끝나면 이름마다 무엇이 들어 있는지 보여 줍니다.
- 컴파일이 실패하면 어느 줄이 왜 걸렸는지 적고, 「이게 무슨 뜻인가요?」를 붙였습니다.
- 프로그램이 칠한 색을 출력 칸이 그대로 그립니다.
- 파일 탭과 화면 탭을 키보드로 옮겨 다닐 수 있게 했습니다.
- 손으로 하는 조작을 실제 터치로 검사하는 도구를 만들고, 누르는 것을 44픽셀로 키웠습니다.

  GitHub 계정도, 내려받기도 필요 없습니다.
- **연습장에 파일 셋**과 예제 칸을 넣었습니다. 예제를 눌러도 쓰던 프로그램이 사라지지
  않습니다.
- 내가 쓴 프로그램을 주소에 실어 보내는 단추를 넣었습니다.
- 없는 주소가 홈 화면을 200으로 돌려주던 것을 404 페이지로 고쳤습니다.
- 가이드의 선수 지식 링크 116개가 죽어 있던 것을 고쳤습니다.
- 가이드 링크로 들어오면 파일 셋이 통째로 지워지던 결함을 고쳤습니다.
- 배포마다 다섯 화면 폭과 두 테마를 회귀 시험하고, 내려받기가 실패했을 때와 실행기가
  느릴 때 무엇이 보이는지도 검사하게 했습니다.
