If Python still feels hard, start with a sentence.

NeedMoreEasy (NME) is a small language that compiles into ordinary Python. Write plain sentences — in English, in Korean, or with both on one line. Sentences alone can carry a whole program; if the day comes when you want real Python, you replace one line at a time, in the same file. There is no second project to start.

    Sentences first
    
    
    Sentences alone can carry a whole program.
    
    
    
      Sentence syntax is not a warm-up you grow out of — it is the language.
      Lists, loops, conditions, questions, waiting, stories, a stopwatch: all of
      it is sayable without a single quote, bracket, colon or equals sign. Two
      more levels exist for the day you want them, and guides 01–12 and 86–88
      use neither.

    Two human languages
    
        
    English and Korean can share a line.
    
        
    
          Every NME word exists in both languages, and mixing them needs no
          declaration. This matters for a first language: you can keep writing
          in whichever words you actually think in.
        
    
        
    
          Error messages carry a stable code such as E0102, and the
          command line will explain any of them in either language.

    Install
    
        
    On your own computer, it runs on your real Python.
    
        
    
          This is the public beta and it builds from source. You need stable
          Rust, Python 3.8 or newer, and Git. Windows, macOS and Linux steps are
          all in the installation guide.
        
    
        
    
          Installation guide ·
          Five-minute guide
        
    
      
    
      
    
        
        
    git clone --branch beta https://github.com/needmoretruth/needmoreeasy.git
cd needmoreeasy
cargo install --path crates/nme-cli --locked
nme --version

nme run examples/hello-sentence
