파이썬이 어렵다면, 문장부터 시작하세요.

NeedMoreEasy(NME)는 평범한 문장을 그대로 파이썬으로 바꾸는 작은 언어입니다. 한국어로 써도 되고, 영어로 써도 되고, 한 줄에 둘을 섞어도 됩니다. 문장만으로 프로그램 하나를 끝까지 만들 수 있고, 파이썬을 쓰고 싶어지는 날이 오면 같은 파일 안에서 한 줄씩 바꿔 나가면 됩니다. 다른 언어로 프로젝트를 다시 시작할 일이 없습니다.

공개 베타 Apache-2.0 파이썬으로 변환 한국어 · 영어

연습장

왼쪽에 쓰면, 오른쪽이 그 파이썬입니다.

이 페이지는 진짜 컴파일러를 브라우저용으로 빌드해서 담고 있고, 그 옆에 파이썬 실행기도 함께 담고 있습니다. 쓰는 동안 바로 변환되고, 실행도 이 탭 안에서 끝납니다. 내가 쓴 프로그램은 이 탭 밖으로 나가지 않습니다.

내 프로그램.nme

        저장 슬롯
        
        
        
      

      
    
    
    

    
    
      
      
    
    

    
    
      
    
      
      
    
    

    
    
      브라우저 안에서 도는 실행기는 RustPython입니다.
      러스트로 만든 별개의 파이썬 구현이고, CPython이 아닙니다.
      파일을 열거나, 네트워크를 쓰거나, PyPI에서 받은 꾸러미를 불러오는 프로그램은
      내 컴퓨터에 NME를 설치해서 실제 파이썬으로 돌려야 합니다.
      그 밖의 것은 이 페이지와 내 컴퓨터에서 같게 동작합니다.
    
    
  
    

    


    
  
    
    
    문장형이 먼저
    
    
    문장만으로 프로그램 하나가 끝까지 만들어집니다.
    
    
    
      문장형은 나중에 버리는 연습용이 아니라 NME 그 자체입니다. 목록, 반복,
      조건, 질문, 기다리기, 이야기, 시간 재기까지 전부 문장으로 말할 수 있고,
      따옴표도 괄호도 콜론도 등호도 쓰지 않습니다. 문법이 두 단계 더 있지만,
      가이드 01~12와 86~88은 둘 다 쓰지 않습니다.
    
    

    
    
      
    
        
    문장형
    
        
    여기서 시작해서, 계속 여기 있어도 됩니다
    
        
    하고 싶은 말을 그대로 씁니다. 가이드 01~12와 86~88이 전부 이 문법입니다.
    
        
    3번 반복해서 환영합니다 말해줘
    
      
    
      
    
        
    초급
    
        
    더 짧게 쓰고 싶어지면
    
        
    같은 뜻을 더 적은 낱말로 씁니다. 파이썬보다 규칙이 적습니다.
    
        
    3번: 말해 "안녕하세요"
    
      
    
      
    
        
    파이썬
    
        
    이미 파이썬을 쓰는 사람을 위해
    
        
    진짜 파이썬이 그대로 남습니다. 한 줄씩 섞어 써도 됩니다.
    
        
    for i in range(3): print(i)
    
      
    
    
    
  
    

    


    
  
    
    
    
      
    
        
    두 언어
    
        
    한국어와 영어가 한 줄에 같이 있어도 됩니다.
    
        
    
          NME의 모든 낱말은 한국어와 영어 양쪽에 다 있고, 섞어 쓸 때 따로 선언할 것이 없습니다.
          처음 배우는 언어에서는 이것이 꽤 중요합니다.
          내가 실제로 생각하는 말로 계속 쓸 수 있기 때문입니다.
        
    
        
    
          오류 메시지에는 E0102 같은 고정 번호가 붙습니다.
          그 번호를 명령 한 줄로 물어보면 한국어나 영어로 길게 풀어서 설명해 줍니다.

    설치
    
        
    내 컴퓨터에서는 내 파이썬으로 돕니다.
    
        
    
          지금은 공개 베타이고, 소스에서 빌드해서 설치합니다.
          안정판 러스트와 파이썬 3.8 이상, 깃이 필요합니다.
          윈도우 · 맥 · 리눅스 방법은 설치 문서에 모두 있습니다.
        
    
        
    
          설치 문서 ·
          5분 안내
        
    
      
    
      
    
        
        
    git clone --branch beta https://github.com/needmoretruth/needmoreeasy.git
cd needmoreeasy
cargo install --path crates/nme-cli --locked
nme --version

nme run examples/hello-sentence.ko
